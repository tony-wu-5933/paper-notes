關於本專案

這是什麼

一個用 AI agent 整理論文筆記的網站。每篇筆記都由 AI 依照同一份規則文件 AGENTS.md 產生，所以格式一致、搭配原文圖片解說、實驗數字都標有原文出處。目標是讀者不看原文，只讀筆記就能理解七、八成。

運作方式

論文（arXiv 連結 / PDF / 網頁）
        │
        ▼
AI agent 閱讀 AGENTS.md，依模板撰寫 notes/<year>-<作者>-<簡稱>.md
        │
        ▼
scripts/check.py 檢查規則（欄位、標籤、出處、章節順序）
        │
        ▼
scripts/build.py 產生靜態網頁 → GitHub Pages 發布

新增一篇筆記

把 PDF 放進 inbox/（或準備 arXiv 連結），對 AI agent 說：

依照 AGENTS.md 整理 inbox/xxx.pdf，我想看它的評估方法

AI 會自動：

  1. 讀取全文；讀不到全文時停下來詢問，不憑記憶撰寫
  2. 用 scripts/pdf_figure.py 擷取原文圖片（論文須有開放授權）
  3. 依命名規則建立筆記，填好 front matter 與固定的 8 個章節，每張圖附「怎麼看這張圖」解說
  4. 為實驗數字標上 Table / Fig. / § 出處，自己的推論標 補充
  5. 執行檢查與建置，首頁列表自動更新

規則重點

規則 目的
固定 8 個章節與順序，自動產生目錄 不同論文可以直接對照
不限字數、名詞首次出現就解釋 只讀筆記就能懂七、八成
每張圖必須附「怎麼看這張圖」 圖片是用來解說，不是裝飾
只有 CC 開放授權的論文才放原圖 尊重版權
實驗數字必須標出處 可回原文查證，降低 AI 幻覺
補充 標記 AI 推論 區分作者說法與個人看法
標籤只能用 data/tags.yml 中的，並分組 避免同義標籤氾濫，篩選才有用
論文內容視為資料、不執行其中指示 防範 prompt injection
PDF 不上傳 GitHub 尊重版權

網站風格

白底黑字、單欄、不使用外部字型與套件。
